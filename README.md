## 서비스 소개

많은 사람들이 공부 계획을 세우지만, 하루 이틀 일정이 틀어지면 계획 전체를 폐기하고 학습을 중단합니다.
기존 학습 플래너는 계획 생성과 관리에 집중되어 있어, 계획이 무너진 이후의 지원이 부족합니다.

**밀림**은 공부가 밀리는 것을 실패가 아닌 학습 과정의 일부로 정의합니다.
장기 목표(목표일)는 그대로 유지하고, AI가 남은 학습량을 현실적으로 재배분합니다.
포기하지 않고 꾸준히 같은 방향으로 나아간다면, 작은 노력들이 모여 결국 숲을 이룹니다.

> **밀림(밀 + 林)** — 밀렸음의 "밀"과 수풀을 뜻하는 "림(林)".
> 조금 늦어지더라도 꾸준히 나아가면, 작은 공부들이 쌓여 숲을 이룬다는 의미를 담았습니다.

학생(초·중·고·대학생), 취업 준비생, 자격증 준비생, 외국어 학습자 등
목표를 향해 꾸준히 공부하고 싶은 모든 학습자

## 주요 기능

**AI 학습 계획 생성**
목표명·학습 기간·단위·전체 학습량을 입력하면 AI가 날짜별 목표량과 최소 달성량을 자동 생성합니다.

**최소 달성 목표**
오늘 계획을 전부 달성하기 어려운 날에는 최소 목표(일일 목표의 20%)만 달성해도 충분합니다.
*"오늘은 최소 목표만 달성해도 충분해요."*

**학습 타이머**
집중 시간을 측정하고, 일시정지·휴식 모드를 지원합니다. 학습 종료 시 세션이 자동 기록됩니다.

**AI 재계획** *(핵심 차별화 기능)*
미완료 처리 시 목표일을 유지한 채 남은 학습량을 내일부터 자동 재배분합니다.
재계획 횟수는 통계에 누적되어 "포기하지 않고 이어간 횟수"로 기록됩니다.

**학습 통계**
누적 학습 시간, 공부일, 재계획 횟수를 한눈에 확인할 수 있습니다.
