### 3. 전체 화면 MVP 구현
IA 구조에 따라 8개 화면 및 공통 컴포넌트 구현 (mock 데이터 기반 UI)

**공통 컴포넌트**
- `Highlighter` — IntersectionObserver 기반 형광펜 애니메이션 (`.hl` + `.hl.lit`)
- `BottomNav` — 홈 / 플랜 / 통계 / 마이 하단 네비게이션, NavLink active 스타일
- `Layout` — 페이지 공통 래퍼 (page-content + BottomNav)

**화면 목록**
| 경로 | 화면 | 주요 기능 |
|------|------|-----------|
| `/splash` | 스플래시 | 로고 + 형광펜 애니메이션, 2.2초 후 로그인으로 자동 전환 |
| `/login` | 로그인 | 카카오 / 구글 소셜 로그인 버튼 UI |
| `/home` | 홈 | 뽀모도로 타이머(25분), 오늘의 계획 체크리스트, 진행률 바, AI 재계획 버튼 |
| `/plan` | 플랜 목록 | 목표별 진행률 카드, D-day 표시, 새 목표 추가 |
| `/plan/new` | 새 목표 만들기 | 3단계 플로우: 목표 설정 → 학습량 설정 → AI 계획 생성 |
| `/plan/:id` | 플랜 상세 | 일별 학습 일정, 완료 체크 표시 |
| `/stats` | 통계 | 주간 바 차트, 월별 학습 히트맵, 요약 지표 카드 |
| `/my` | 마이페이지 | 프로필, 학습 요약, 설정 메뉴, 로그아웃 |
