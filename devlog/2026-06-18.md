### 8. DB 스키마 설계 및 RLS 정책 작성

`supabase/schema.sql` 파일 작성 (Supabase SQL Editor 실행용)

**테이블 4개**

| 테이블 | 역할 |
|---|---|
| `milrim_profiles` | 사용자 프로필 |
| `milrim_plans` | 학습 목표/계획 |
| `milrim_plan_days` | AI 생성 일별 계획 |
| `milrim_study_sessions` | 타이머 학습 기록 |

**보안 설계**
- 모든 테이블 RLS 활성화
- SELECT/INSERT/UPDATE/DELETE 정책 (본인 데이터만)
- UPDATE에 `WITH CHECK` 추가 (소유권 변조 방지)
- `UNIQUE(plan_id, date)` — 같은 날 중복 계획 방지
- 양수 CHECK 제약 — 음수 학습량 방지
- 신규 유저 가입 시 프로필 자동 생성 트리거 (`handle_new_user`)
