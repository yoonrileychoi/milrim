### 2. 관리자 권한 분리 (`App.tsx`, `Sidebar.tsx`, `MyPage.tsx`, `AdminPage.tsx`)

**권한 체계**
- Supabase Auth `app_metadata.milrim_role: admin` 기반으로 관리자 계정 지정
- `app_metadata`는 서비스 롤 키 또는 대시보드에서만 수정 가능 (유저 직접 수정 불가)
- SQL Editor에서 아래 쿼리로 관리자 지정:
  ```sql
  UPDATE auth.users
  SET raw_app_meta_data = raw_app_meta_data || '{"milrim_role": "admin"}'::jsonb
  WHERE id = (SELECT id FROM auth.users WHERE raw_user_meta_data->>'email' = '관리자이메일');
  ```

**구현 내용**
- `App.tsx`: `AdminRoute` 컴포넌트 추가 — 비관리자 접근 시 `/home` 리다이렉트
- `Sidebar.tsx`: 관리자 메뉴 조건부 노출
- `MyPage.tsx`: 관리자 모드 진입 버튼 조건부 노출
- `AdminPage.tsx`: 페이지 내부 이중 보호 (라우트 우회 시에도 잠금 화면 표시)

**Edge Function: `admin-delete-user`**
- 관리자 권한 검증 후 서비스 롤 키로 `auth.users` 삭제 (cascade 삭제)
