# 개발일지 — 2026-07-19

## 작업 내용

### 1. AI 계획 분배 검증 강화 (`supabase/functions/generate-plan/index.ts`)

**배경**: 원래는 Solar에게 "학습 가능 시간에 비례해 분배"라고만 지시하고 구체적인 계산은
Solar 자유도에 맡겨뒀다. 국내 LLM의 실제 판단력을 보여주려면 계산까지 맡기는 게 맞다고
봤기 때문이다.

**문제 발견**: 하루 학습 가능 시간이 모든 날짜에 동일한데도, Solar가 근거 없이 크게
불균등한 분배를 만들어내는 사례가 나왔다 (예: 260문제·3일을 90/90/80으로). "AI 메이트의
한 마디" 코멘트도 실제 숫자와 다른 설명("날짜마다 학습 가능 시간을 고려했다")을 내놓는
경우가 있었다.

**1차 수정과 재발견**: 서버에서 분배 결과의 균등성(최댓값-최솟값 차이 1 이하)을 검증해
문제 있는 분배를 걸러내도록 했다. 그런데 Solar에게 여전히 계산 자유도를 준 채로 이 검증만
추가하다 보니, Solar가 조건을 못 지켜 수학 계산(fallback)으로 넘어가는 빈도가 늘었고,
이때 AI 코멘트도 함께 비워지면서 "AI 메이트의 한 마디"가 아예 안 뜨는 경우가 잦아졌다.

**최종 수정**: 모든 날짜 조건이 완전히 동일한 이 상황에서는 "자유도"가 실제로는 판단력을
보여줄 재료가 없다고 결론짓고, Solar에게 정확한 분배 계산 공식(`base = floor(total/days)`,
`extra = total - base*days`, 앞에서부터 extra개 날짜만 `base+1`)을 그대로 지시해 계산의
신뢰성을 확보했다. 대신 "왜 이렇게 나눴는지 설명하는 코멘트"는 이전과 동일하게 Solar가
자유롭게 생성하도록 뒀다. 지금은 계산식을 그대로 지시했지만, 추후 사용자별 학습 패턴을
반영하는 기능이 추가되면 이 부분도 Solar가 직접 판단하는 방식으로 다시 고도화될 예정이다.

### 2. Solar 응답 진단 로그 추가 (`generate-plan/index.ts`)

- `solar days check` — 분배 배열 형식·합계·균등성
- `solar comment check` — 코멘트 존재 여부·길이·미리보기
- `final result` — 최종 생성 방식(`solar`/`fallback`), 코멘트 저장 여부

### 3. 로그로 확인한 동작
- Solar가 균등 조건을 못 지킨 응답(예: [85,85,90], 차이 5) → fallback 전환 확인
- fallback 시 AI 코멘트도 함께 비워져, 화면 숫자와 다른 설명이 노출되지 않는 것 확인
