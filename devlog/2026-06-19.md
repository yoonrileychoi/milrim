### 3. AI 계획 생성 Edge Function 연동 (`supabase/functions/generate-plan/`)

**아키텍처**
- 브라우저 → Supabase Edge Function → Solar (Upstage) API
- Edge Function 실패 시 → 브라우저 수학적 분배 fallback (이중 안전망)
- API 키는 Supabase Secrets에만 보관 (소스코드 미노출)

**Solar API 호출**
- 엔드포인트: `https://api.upstage.ai/v1/solar/chat/completions`
- 모델: `solar-mini`
- 일자별 target_amount, min_amount 배열 생성 후 `milrim_plan_days` INSERT

**수학적 분배 알고리즘** (fallback)
```
남은 학습량 / 남은 일 수 → ceil → 다음 날 분배
마지막 날: 나머지 전량
min_amount: max(1, ceil(target × 0.2))
```

### 4. AiLoadingPage 핵심 버그 수정 (`AiLoadingPage.tsx`)

| 버그 | 원인 | 해결 |
|---|---|---|
| 계획 생성 후 일자별 계획 없음 (신규 플랜) | `getSession()` null 반환 시 userId undefined → 조기 return, 2800ms 후 navigate | `useAuth()` hook으로 user 직접 사용 |
| 계획 수정 후 아무것도 안 됨 | 기존 plan_days 있는데 INSERT → UNIQUE 제약 위반 | INSERT 전 DELETE 추가 |
| `study_seconds` NOT NULL 제약 위반 | rows에 `study_seconds` 필드 미포함 | `study_seconds: 0` 추가 |
| navigate가 minWait 무시 | navigate가 `run()` 안에 있어서 2.8초 대기 무효 | `Promise.all([run(), minWait]).then(navigate)` 구조로 수정 |

### 8. 타이머 일시정지/재개 시간 보존 수정

**문제**: 일시정지 후 "계속 공부하기" 시 타이머가 0에서 재시작 → 최종 기록 시간이 잘못 저장됨

**수정 사항**

`TimerPage.tsx`
- `TimerState` 인터페이스에 `initialSeconds?: number` 추가
- `useState(initialSeconds ?? 0)` — 재개 시 누적 시간 이어서 시작

`RestPage.tsx` (전면 개선)
- `useLocation` state로 planId, planDayId, seconds 수신
- "지금까지 집중한 시간" — 실제 경과 시간 표시 (기존 하드코딩 제거)
- "계속 공부하기" — `initialSeconds: seconds` 포함해서 TimerPage로 복귀
- "끝내기" — `milrim_plan_days` UPDATE + `milrim_study_sessions` INSERT 후 IncompletePage 이동

| 오류 | 원인 | 해결 |
|---|---|---|
| Edge Function 401 | JWT 인증 실패 | 클라이언트 fallback으로 처리 |
