### 3. AI 계획 생성 Edge Function 연동 (`supabase/functions/generate-plan/`)

**아키텍처**
- 브라우저 → Supabase Edge Function → Solar (Upstage) API
- Edge Function 실패 시 → 브라우저 수학적 분배 fallback (이중 안전망)
- API 키는 Supabase Secrets에만 보관 (소스코드 미노출)

**Solar API 호출**
- 엔드포인트: `https://api.upstage.ai/v1/solar/chat/completions`
- 모델: `solar-mini`
- 일자별 target_amount, min_amount 배열 생성 후 `milrim_plan_days` INSERT

**수학적 분배 알고리즘** (fallback)
```
남은 학습량 / 남은 일 수 → ceil → 다음 날 분배
마지막 날: 나머지 전량
min_amount: max(1, ceil(target × 0.2))
```

### 14. AI 재계획 수학 버그 수정 (`ReplanPage.tsx`)

**문제**: 30강 7일 계획에서 하루 못 하고 재계획 시, Solar AI가 생성한 잘못된 분배(1일 3강 + 6일 4강 = 27강)가 그대로 남아 있거나, 재분배 후 합계가 맞지 않음

**수정**
- 분배 알고리즘을 `ceil` 방식 → `base + extra` 방식으로 변경
  - `base = Math.floor(remainingAmount / totalDays)`
  - `extra = remainingAmount % totalDays`
  - 앞에서부터 `extra`개 날만 `base + 1`, 나머지는 `base` → 합계가 정확히 remainingAmount
- 재분배 기준을 **내일부터** 고정 (오늘은 incomplete 유지, 삭제하지 않음)
- `tomorrowStr` 이후 날짜만 DELETE 후 재INSERT

### 16. 프로필 닉네임 저장 즉시 반영 수정

**문제**: `supabase.auth.updateUser()` 호출 후 마이페이지로 이동해도 닉네임이 바뀌지 않음

**원인**: `onAuthStateChange`가 `updateUser` 이벤트에 대해 즉시 반응하지 않아 AuthContext의 `user` 상태가 갱신되지 않음

**수정**

`AuthContext.tsx`
- `refreshUser()` 함수 추가 — `supabase.auth.getUser()`로 최신 user 직접 조회 후 state 갱신
- 컨텍스트 타입 및 기본값에 `refreshUser` 포함

`ProfilePage.tsx`
- `updateUser` 성공 후 `await refreshUser()` 호출 → MyPage 이동 시 닉네임 즉시 반영

## 발생한 오류 및 해결

| 오류 | 원인 | 해결 |
|---|---|---|
| Edge Function 401 | JWT 인증 실패 | 클라이언트 fallback으로 처리 |
| 계획 생성 후 일자별 계획 미표시 | `getSession()` null 반환 시 조기 return | `useAuth()` user 직접 사용 |
| 계획 수정 후 silent fail | 기존 plan_days UNIQUE 위반 | INSERT 전 DELETE |
| `study_seconds` 오류 | NOT NULL 필드 미포함 | 모든 row에 `study_seconds: 0` 추가 |
| 타이머 재개 시 0 시작 | TimerPage `useState(0)` 고정 | `useState(initialSeconds ?? 0)` |
| 재계획 합계 오류 | `ceil` 분배 방식으로 합계 초과 | `base + extra` 균등 분배로 교체 |
| 미래 날짜 색상 회색 | `isToday ? green : grey` 조건에 미래 미포함 | `isFuture`도 초록 처리 |
| 닉네임 저장 후 미반영 | `onAuthStateChange` 미발화 | `refreshUser()` 명시적 호출 |
| 한국어 git commit 깨짐 | PowerShell heredoc 인코딩 | 영문 커밋 메시지 사용 |
